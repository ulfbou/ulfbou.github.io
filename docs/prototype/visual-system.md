# Visual system

Create one continuous editorial page, not a CV, dashboard, template gallery, or IDE imitation. Begin spaciously, use an orbit/facet motif as meaningful navigation, transition to a darker expandable work field, present artifacts as readable content, and finish with working principles.

Use at most display, body, and monospace roles. Prefer stable system/open fonts. Project accents never carry meaning alone. Contrast must pass in normal, hover, focus, expanded, and print states.

Motion may clarify selection/expansion but is never required. Respect reduced motion; avoid parallax, cursor following, continuous orbiting, and disruptive layout movement.

Narrow layouts retain essential facts, use touch-sized controls, prevent overflow, and simplify the orbit when needed. Release requires landmarks, headings, native controls, visible focus, labels, expanded state, predictable order, no hover-only content, non-color distinctions, selection, zoom resilience, and image alternatives.

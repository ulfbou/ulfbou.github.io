# Initial decisions

- D-001: The product is one dynamic portfolio page, not a conventional CV.
- D-002: Human story first; evidence is progressively available.
- D-003: Structured content owns meaning; components own presentation.
- D-004: Keep .NET 10 Blazor WebAssembly and GitHub Pages.
- D-005: Facets and expansion operate in place rather than fragmenting routes.
- D-006: Ulf is final publishing authority; evidence and generated text are candidates.
- D-007: Deterministic validation precedes probabilistic assistance.
- D-008: Tools emerge only from demonstrated content needs.
- D-009: Never use quantity metrics as quality or credibility scores.
- D-010: Code, terminal, diagrams, and demos are accessible explained content, not decoration.
- D-011: Reorganization is allowed; semantic loss, contradiction, overclaiming, lost authority, and unreviewed publication are not.
- D-012: The original brainstorm is an opportunity map, not a backlog or governing contract.
